# 模型博物馆 · 打开计算的内部

纯前端、零构建、离线可打开的中文 3D 教具。概览有十一件展品，包括原有六件；进入模型后晶体全部退场，只显示该模型独立的计算结构。**不是推理工具**：不加载权重、不执行训练，数值、图像与置信度都是明确标注的教学演示。

## 打开

从仓库根目录启动本地服务（Windows 和 Ubuntu 通用）：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Ubuntu 可使用 `python3`，Windows 可使用 `py -3`。浏览器访问
`http://127.0.0.1:8000/site/`，按 `Ctrl+C` 停止服务。也可以直接打开 `site/index.html`。
原 Ubuntu 菜单快捷方式是本机配置，不随仓库迁移；其他电脑请自行创建快捷方式。


`vendor/three.min.js` 仍是本地 Three.js r149 UMD，未增加运行依赖、包管理器或构建步骤。需要浏览器支持 WebGL；无法创建上下文、或上下文丢失时会显示中文错误说明。

## 交互

- 顶部可横向滚动的展品按钮或概览晶体：切换模型，进入独立结构。默认播放一次，完成后停留，不自动循环。
- 点 3D 部件、浮动标签或说明区编号按钮：暂停并锁定部件，展示直觉、张量尺寸 / 计算与对应代码。播放恢复后保留锁定，便于对照。
- **暂停 / 继续**保留当前阶段及数据位置；**单步**推进一个阶段并保持暂停；**重置**回第一阶段并暂停；速度支持 0.5× / 1× / 2×。
- 底部每段进度条都是有名称的阶段按钮，点击可回看并恢复跟随阶段的部件说明。
- **视角复位**恢复完整结构取景；拖动旋转，滚轮缩放。
- 画布有键盘焦点时：空格暂停 / 继续，左右方向键前后单步。按钮与下拉框保留各自原生键盘语义，不劫持空格。
- 返回概览或 Esc：晶体重新出现，播放控件禁用。
- 标签编号与说明区一致；● 标记当前阶段，选中标签独立高亮。手机非当前部件使用短编号，当前部件与锁定部件保留完整名称，避免文字盖住结构。
- ≤900px 默认上下分区，3D 与说明可同时看；手机横屏改为左右分区。说明独立滚动，播放控制常驻，不用关闭抽屉才能看 3D。
- `prefers-reduced-motion` 下取消入场 / 相机过渡，切换模型默认暂停；仍可主动播放或单步。切到后台自动暂停。

## 历史入门与原有六套结构

推荐先看约 1950 年代符号规则、约 1958 年感知机、约 1980 年代多层感知机与反向传播，再看约 1980—90 年代卷积和循环网络，最后探索原有六件。年代与概念均是近似的教学划分；研究分支并行发展，多层网络与反向传播也有更早的历史，并非线性继承。

新增五件均有独立部件、连线、阶段和代码片段：符号前向规则推理、线性阈值与感知机学习规则、多层网络的前向及反向传播、共享卷积与池化、共享参数的时间展开循环。图形和动画是固定示意，不执行计算或训练；纹理不按标注尺寸逐像素绘制。

原有六件：

| 模型 | 可见结构与数据 | 阶段语义 |
|---|---|---|
| Transformer | 四枚词元堆叠、Q/K/V 三分支、4×4 下三角因果矩阵与未来 ×、两头立体叠层、拼接投影、残差跨接、FFN 宽窄层 | T=4、d=8、h=2、d_k=4；每头并行计算，最后词表输出；省略 LayerNorm 与位置编码内部 |
| YOLO | 图像格、80² / 40² / 20² 递减的多通道立体特征、FPN 自顶向下融合边、三个检测头、候选框 | 三候选 A=.92、B=.81、C=.88；示意 IoU(A,B)=.72 > .45，NMS 隐去 B；不绑定具体 YOLO 版本 |
| autograd | 球形输入、乘法 / 加法算子、损失多面体，以及 x 到加法的复用边 | x=2,w=3,a=6,b=8,L=64；先前向，根梯度设 1，再逆拓扑传播；梯度标注依次变为 dx=16→64、dw=32 |

## 教学边界与修正

- 所有代码明确标为**简化片段、非完整可运行程序**。变量、网络层、拓扑排序、mask、调度器和优化器等需在实际项目中定义，不能把这里的演示当作训练脚本。
- autograd 的 `L.grad = 1` 必须在逆拓扑遍历**之前**设置；独立反传前清零，复用结点使用 `+=` 累加。前向与反向动画按真实依赖分别激活，不把梯度当作倒放所有前向边。
- LoRA 统一为 PyTorch 权重布局 `[d_out,d_in]`，因此 `A:[r,d_in]`、`B:[d_out,r]`，`ΔW=(α/r)BA`；避免原文的 A/B 维度与公式不一致。合并后停用低秩旁路，防止重复计算。
- DDPM 均值为 `μ_t = (x_t − β_t εθ / √(1−ᾱ_t)) / √α_t`，后验噪声方差为 `β̃_t`，最后一步不加噪。这里不把训练 1000 步调度器直接截成 50 步当作合法加速采样。
- YOLO 使用通用结构示意，不混用不同版本的 objectness、DFL、框解码与损失，也不展示无来源的 mAP / 百分比断言。
- PPO 的 clip 是 surrogate objective 中的一条分支，不是硬约束概率比。单步 TD 残差仅为 GAE 的教学起点，真实实现还需终止掩码、多步轨迹、价值损失和熵项。

## 文件结构与扩展

- `index.html`：语义化布局、画布、部件说明、阶段与播放控件。
- `styles.css`：继承原深色青紫设计、响应式轨道、键盘焦点、减少动态偏好。
- `data.js`：模型概览、公式、教学边界。
- `parts.js`：独立部件元数据。每项含 `id / label / kind / pos / size / shape / idea / code`；`edges` 描述真实依赖，`phases` 描述阶段及活动部件。
- `anim.js`：可复用立体元素构造器、专属形态、示意格纹、边、暂停时钟和阶段可视状态；负责资源释放。
- `scene.js`：概览、相机、自写旋转缩放、部件射线拾取、标签投影与避让。
- `app.js`：模型 / 部件选择、阶段与控件同步、键盘与后台暂停。
- `design-contract.md`：任务的教学使命、继承令牌与界面规则。

新增模型应同时配置模型说明与部件拓扑；形态不同的算子在 `anim.js` 中新增 `kind`，不要再退回所有模型共用一条薄板管道。小尺寸格纹是示意，不按真实通道数量创建数万个网格物体。

## 原有版本的验证记录

使用静态 HTTP 服务与 Chromium / Playwright 实际执行：六模型切换、44 个部件逐一画布射线点击、编号按钮、暂停时钟冻结、单步、重置、速度、阶段回看和完成状态、键盘焦点与空格 / 方向键、减少动态偏好、`file://` 离线入口。

响应式检查覆盖 1440×900、1024×768、768×1024、390×844、320×568、844×390，逐模型逐阶段检查标签交叠与越界、文档横向溢出、控制区位置；修复横屏 PPO 标签交叠并复测。WebGL 实际帧有非透明绘制像素且 `gl.getError()=0`。无页面脚本异常；软件渲染浏览器有截图读回导致的 `GPU stall due to ReadPixels` 性能警告，无应用级控制台错误。

本项目无构建 / TypeScript 步骤；五个应用脚本均通过 `node --check`。浏览器预览已打开 `site/index.html`，布局与交互证据来自实际浏览器自动化测量，不将预览工具描述为截图审查工具。
