# 教学展厅设计约定

使命：先看结构与数据，再点部件理解张量和代码；所有数值均为教学演示，不执行模型推理。

继承现有设计：深色背景 #05070f、浅色文字 #e8eefc、次级文字 #8b9bb8、青色强调 #46e0ff、紫粉辅助色；六模型沿用原展品色。中文系统字体，代码用系统等宽字体。字号 12 / 14 / 16 / 24 / 32px；间距 4 / 8 / 12 / 16 / 24 / 32px；圆角 8 / 16 / 24px。边框用于区分教学层级，不依赖发光。状态切换使用 180ms 颜色反馈与 360ms 渐进收敛入场；减少动态偏好下立即切换且默认暂停。

应做：独立可旋转模型；明显中文标签；可键盘操作的等价部件列表；当前阶段与手动选中部件分别呈现；窄屏上下分区且画布保持可见；长代码局部换行；暂停、单步、重置、速度与视角复位。
不要：把每个模型变成同一薄板流水线；把示意数值写成性能结果；全屏浮层遮住手机画布；用裁切隐藏布局错误；持续装饰自转；新增在线依赖或改动 Python 任务。

假设：这是理解结构的交互教具，不是训练/推理工具；以小张量和标量例子解释真实结构，省略的归一化、优化器与网络细节需明确说明。
